## 1. КОПИРАЙТИНГ ГАЙДЛАЙНЫ (D-01: закрыт)

### 1.1 Универсальные запреты (ВСЕ индустрии)

**ЗАПРЕЩЁННЫЕ фразы (AI slop):**
- "Revolutionize your..." / "Transform your workflow"
- "Unlock the power of..." / "Unleash the potential"
- "Cutting-edge" / "Next-generation" / "Game-changing"
- "Seamless integration" / "Seamlessly"
- "Leverage AI to..." / "Harness the power"
- "In today's fast-paced world"
- "One-stop solution" / "All-in-one platform"
- "Take your X to the next level"
- "We're passionate about..."
- "Lorem ipsum" / любой placeholder

**Правила хорошего копирайтинга:**
1. **Конкретность:** "Reduce deployment time by 40%" НЕ "Speed up your workflow"
2. **Голос клиента:** "Stop wasting 3 hours on manual reports" НЕ "We provide reporting solutions"
3. **Benefit > Feature:** "Ship code without fear" НЕ "Automated CI/CD pipeline"
4. **Один CTA = одно действие:** "Start Free Trial" НЕ "Learn More / Get Started / Contact Us" (все одновременно)
5. **Числа > прилагательные:** "Used by 12,000 teams" НЕ "Trusted by many companies"

### 1.2 По индустриям

**SaaS / Tech:**
- Тон: уверенный, технически грамотный, без hype
- CTA: "Start Building Free" / "Deploy in 5 Minutes" / "See Demo"
- Hero: проблема → решение в одном предложении
- Пример: "Ship 3x faster. Zero configuration needed."

**Corporate / B2B:**
- Тон: профессиональный, доверительный, результат-ориентированный
- CTA: "Schedule a Consultation" / "Request a Proposal" / "Talk to Sales"
- Hero: результат для бизнеса клиента
- Пример: "Enterprise security that scales with your ambitions."

**Startup / Product Launch:**
- Тон: энергичный, прямой, дерзкий
- CTA: "Join the Waitlist" / "Get Early Access" / "Be First to Try"
- Hero: bold statement + urgency
- Пример: "The spreadsheet is dead. Meet what comes next."

**Luxury / Premium:**
- Тон: сдержанный, элегантный, минимум слов
- CTA: "Discover the Collection" / "Book a Private Viewing" / "Inquire"
- Hero: atmosphere > information
- Пример: "Where craftsmanship meets eternity."

**Restaurant / Local:**
- Тон: тёплый, приглашающий, personal
- CTA: "Reserve a Table" / "View Our Menu" / "Order Now"
- Hero: sensory language (вкус, атмосфера)
- Пример: "Farm-fresh ingredients. Wood-fired flavors. Your table awaits."

**Auto Import / Car Service:**
- Тон: надёжный, экспертный, прозрачный
- CTA: "Рассчитать стоимость" / "Получить консультацию" / "Подобрать авто"
- Hero: выгода + прозрачность
- Пример: "Авто из Кореи и Японии. Полный расчёт за 2 минуты."

## 2. СТРУКТУРА КОНТЕНТА ДЛЯ СЕКЦИЙ (D-03: закрыт)

### Hero
```
Overline:     3-5 слов (optional) — "Trusted by 10,000+ teams"
Headline:     5-12 слов — главная ценность, одно предложение
Subheadline:  15-30 слов — раскрытие headline, конкретика
CTA Primary:  2-4 слова — "Start Free Trial"
CTA Secondary: 2-4 слова (optional) — "Watch Demo"
Visual:       Hero image / video / animation
```

### Features
```
Section heading: 3-8 слов — "Everything you need to ship faster"
Section subheading: 15-25 слов (optional)
Per feature:
  Icon:         1 Lucide icon
  Title:        3-5 слов
  Description:  15-30 слов — конкретная польза
Features count: 3, 4, или 6 (для grid)
```

### Testimonials
```
Quote:        20-50 слов — конкретный результат, не общие слова
Name:         Полное имя
Role:         Должность + компания
Photo:        Headshot (square, min 128px)
Optional:     Компания logo, rating stars
Count:        3-6 отзывов
```

### Pricing
```
Per tier:
  Name:        1-2 слова — "Starter" / "Pro" / "Enterprise"
  Price:       "$X/mo" или "Custom"
  Description: 8-15 слов — для кого этот план
  Features:    5-8 пунктов (✓/✗)
  CTA:         "Get Started" / "Contact Sales"
  Badge:       "Most Popular" на рекомендуемом
Tiers count:   2 или 3
```

### FAQ
```
Per item:
  Question:    Настоящий вопрос клиента (не "What is your product?")
  Answer:      30-80 слов — конкретный ответ
Items count:   5-8
```

### Stats
```
Per stat:
  Number:      Конкретное число (не "many" или "lots")
  Label:       2-4 слова
  Optional:    "+" или "%" suffix
Stats count:   3 или 4
Example:       "12,000+" / "Active Teams"
```

## 3. ШАБЛОН КЛИЕНТСКОГО БРИФА (F-01: закрыт)

### Обязательные поля (без них НЕ начинаем)

```
1. НАЗВАНИЕ КОМПАНИИ / ПРОЕКТА:
2. ЧЕМУ ПОСВЯЩЁН САЙТ (в 1-2 предложениях):
3. ЦЕЛЕВАЯ АУДИТОРИЯ (кто будет смотреть):
4. ГЛАВНОЕ ДЕЙСТВИЕ посетителя (что должен сделать):
   □ Оставить заявку  □ Купить  □ Записаться  □ Скачать
   □ Подписаться  □ Позвонить  □ Другое: ___
5. ЯЗЫК САЙТА: □ Русский  □ English  □ Оба
```

### Желательные поля (улучшают результат)

```
6. СТИЛЬ / НАСТРОЕНИЕ:
   □ Минималистичный  □ Яркий  □ Тёмный/Технологичный
   □ Роскошный  □ Тёплый/Уютный  □ Покажу примеры
7. ПРИМЕРЫ САЙТОВ КОТОРЫЕ НРАВЯТСЯ (1-3 ссылки):
8. ЛОГОТИП: □ Есть (приложить)  □ Нет (сгенерировать)
9. ФИРМЕННЫЕ ЦВЕТА: □ Есть (какие)  □ На ваше усмотрение
10. ФОТОГРАФИИ / ИЗОБРАЖЕНИЯ: □ Свои (приложить)  □ Стоковые
11. ТЕКСТ / КОНТЕНТ: □ Предоставлю  □ Написать за меня
12. СЕКЦИИ которые точно нужны:
    □ О компании  □ Услуги  □ Портфолио  □ Цены
    □ Отзывы  □ FAQ  □ Блог  □ Контакты  □ Калькулятор
13. ОСОБЫЕ ТРЕБОВАНИЯ / ИНТЕГРАЦИИ:
```

### Обработка неполного брифа

Если клиент предоставил только поля 1-5:
1. Определить тип сайта → выбрать блюпринт
2. Определить стиль → выбрать пресет автоматически
3. Сгенерировать контент по гайдлайнам индустрии
4. Использовать стоковые изображения (Unsplash стиль)
5. **ОБЯЗАТЕЛЬНО:** показать клиенту и спросить до финализации

## 4. СТРАТЕГИЯ PLACEHOLDER КОНТЕНТА (D-02: закрыт)

### Правила

1. **НИКОГДА** Lorem Ipsum — всегда реалистичный текст
2. Placeholder текст ДОЛЖЕН быть релевантным индустрии
3. Числа в stats — реалистичные (не "1,000,000 customers" для стартапа)
4. Имена в testimonials — реалистичные (не "John Doe")
5. Фотографии — описание в alt, placeholder-изображения через /placeholder

### Шаблон placeholder текста по секциям

```
Hero headline:     "[Конкретная выгода] для [аудитория]"
Hero subheadline:  "[Как работает] [с какой скоростью/качеством] [без какой боли]"
Feature title:     "[Действие] [что]" — "Automate Deploys", "Track Analytics"  
Feature desc:      "[Решение] [проблемы] за [время/шаги]"
Testimonial:       "Since switching to [Product], we've [конкретный результат с числом]. [Имя], [Должность] at [Компания]."
FAQ question:      "Как [типичное действие пользователя]?"
Stat:              "[Число][+/%] [что измеряем]"
```

## 5. ПРОЦЕСС ИТЕРАЦИИ (F-02: закрыт)

### Workflow: клиент → генерация → правки

```
ЭТАП 1: БРИФ
  → Получить бриф (обязательные поля минимум)
  → Выбрать блюпринт + пресет + шрифтовую пару
  → Подтвердить выбор с клиентом (если возможно)

ЭТАП 2: ПЕРВАЯ ВЕРСИЯ
  → Сгенерировать через Artifact канал (preview)
  → Self-check по scoring rubric
  → Показать клиенту

ЭТАП 3: ПРАВКИ (максимум 3 раунда)
  Раунд 1: Крупные изменения (структура, стиль, секции)
  Раунд 2: Средние (цвета, тексты, порядок)
  Раунд 3: Мелкие (typos, spacing, финальные штрихи)
  
  ПРАВИЛО: Каждый раунд правок → повторный self-check
  ПРАВИЛО: Новая правка не должна ломать уже утверждённое

ЭТАП 4: ФИНАЛИЗАЦИЯ
  → Production генерация через Claude Code
  → npm run build — проверка
  → Деплой на VPS / Vercel
  → Финальная проверка в браузере
```
