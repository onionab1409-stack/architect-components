# Architect Components

Premium AI website generator built on **226 UI components**, **6 layout components**, and **3 hooks** from Aceternity UI, Magic UI, Motion Primitives, and shadcn/ui.

## Stack

- **Next.js 16** (App Router, Server Components)
- **React 19** + TypeScript (strict)
- **Tailwind CSS v4** (oklch colors, `@theme inline`)
- **Motion 12** (ex framer-motion)
- **GSAP 3.14** + SplitText + ScrollTrigger
- **Lenis** smooth scroll
- **Three.js 0.183** for 3D components

## Quick Start

```bash
npm install
npm run dev
```
